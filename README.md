# Assignment 7 - Chat

I made 3 tables: users, channels and messages. Each message has user_id and channel_id as foreign keys, so you can't add a message from a user or to a channel that doesn't exist. For the ids I used BIGSERIAL because the server is supposed to get millions of messages and a normal INTEGER could run out one day, BIGINT basically can't. For the time I used TIMESTAMPTZ because the users are from different countries, it saves the real moment the message was sent so the order is correct even if two people are in different time zones. I don't store how many messages a user has, because that can always be counted from the messages table and it would only get out of date.
